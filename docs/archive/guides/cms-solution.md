# Admin login and content editing

> This page used to say three processes were current: a frontend, a CMS API, and Strapi, and it published a seed password. None of that is how evig runs. Do not start a `cms-api`. Do not use any credential this page used to print.

Admin login is the same account as the rest of the app. Staff is `users.is_staff`. See `src/lib/permissions.ts` and `docs/UNIFIED_AUTH.md`.

The previous text of this page is in git history. Do not restore it, and do not use any credential it printed.
